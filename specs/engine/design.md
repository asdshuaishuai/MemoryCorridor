# 实现设计

总体设计沿 PROPOSAL §4–14。先交付 native CLI 闭环，再实现检索扩展、MCP、视觉与分发。

- base 提供严格 JSON/路径工具、SHA-256；core 定义条目、来源与页面校验；decl 负责文学化格式的固定声明前导和受限字面量解析，生成同一可编译代码；vault 实现基于内容的变更计划与校验；index 提供关键词/向量/图数据处理；agent 管理协议、工单和编排。
- native platform 仅提供文件系统、锁、同步替换、枚举和编译器调用能力。系统适配不吞错、不回退为非原子覆盖。已验证平台为 macOS 与 Linux（CI 单 job）；跨平台交付由 WASM 运行时 + 薄宿主承担（见 docs/wasm.md），不再要求各平台原生适配。
- stdin/stdout 采用一行 JSON 请求/结果，显式 op 和 vault；便于路径、正文及 schema 参数表达。命令语义与方案一致，传输参数不依赖 shell 分词。
- 目录条目含 id/path/kind/format/sha256/sources/stale；内容不内嵌。代码声明使用固定纯构造器和字面量；解析器不执行文件中的任意代码。生成目录可由独立 moon check 检验；旧六字段目录只在读取时按路径迁移格式。
- 提交先落持久化事务日志，包含前/后内容与根声明；获取进程级 vault 锁并检查基线。准备后按计划写正文和状态，根声明最后发布；恢复时按提交点决定回滚或完成；缓存只在一致版本构建。
- 所有来源哈希、正文哈希与目录引用须核验；人类编辑不自动覆盖，提供可检查的显式登记流程。提交/取消后暂存草稿保留供检查，不自动删除；未来清理只能作用于所属工单。
- 默认暴力向量后端通过核心接口实现，向量空间和正文版本参与有效性验证。宿主负责模型与外部检索接入。
- index/context.mbt 提供查询词覆盖的段落选择、长段落词定位和 UTF-8 区间；检索与图候选按排名分配剩余预算，完全重复正文保留独立引用后只装配一次。agent 负责装配前的来源/正文校验，CLI/MCP/Web 使用同一实现。
- views/*.mbt.md 单独声明可视页面；视觉宿主对接知识数据，已评估 MoonViz 的 SVG 入口；首版为可选择长文本的 MoonBit HTML 渲染器，详情见 docs/visual-mbtmd.md。
- web 包是固定 vault 的 MoonBit 原生 loopback HTTP 薄适配（socket 走 platform 的 native FFI），读取和搜索经 nativehost 进程内派发给引擎，页面来自文学化编译，不维护桌面应用或专用桌面集成。

验收包括纯函数反例、临时 vault 端到端、类型错误/路径漂移、每个提交中断点、进程锁、缓存损坏/重建、模型空间隔离、视觉实际交互与源码占比。
