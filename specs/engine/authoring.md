# 外部 Agent 编写协议

MoonBit 核心不调用模型或网络。任意外部 Agent 经 CLI/MCP 读取上下文、提交分析和结构化页面，再交由引擎编译发布；本仓不维护桌面控制器、应用构建阶段或内置模型服务。

- `context` 返回来源全文、既有页面、研究目的、`context_token` 和稳定的 `source_summary_id`。令牌绑定来源/页面/目的的完整登记元数据与失效状态；变更后重新读取上下文并分析。
- 自动调用方在 `analysis-submit`、`draft-submit`、`commit` 回传令牌，以拒绝过期分析、并发上下文刷新和生成期间的外部编辑。旧手工分析/提交可省略令牌。
- `draft-submit` 每页精确为 `{id,kind,title,sources,tags,body}`。引擎派生规范 frontmatter 和路径，整批校验来源、互链、类型及上下文后写入内容寻址 staging；不发布目录。接受 1–32 页、总文本不超过 1 MiB。
- `commit` 是实际 MoonBit 编译和可恢复事务的发布边界。失败不部分发布，已提交工单重放不重复写入；取消/失效输入不能跳过校验。
- 工单记录的 `context_version` 兼容旧记录缺失；重新读取上下文时要求刷新分析。分析和草稿保留用于重试。

`scripts/authoring_e2e.py` 已纳入完整门禁，使用真实 native、磁盘与编译器验证整批拒绝、Unicode frontmatter、暂存/发布边界、重放、编译拒绝、人类登记编辑、竞争上下文、其他来源元数据变化和提交前来源漂移。移除完整元数据比较曾使过期草稿回归失败，恢复后通过。

结构校验与编译无法证明正文的语义正确性。外部 Agent 仍须验证事实、单位、缺失数据和来源支持度；多领域模型质量/成本对照保持未完成。
