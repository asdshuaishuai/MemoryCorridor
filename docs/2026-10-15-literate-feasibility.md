# 文学化索引可行性与验证记录

日期：2026-10-15。性质：设计修订与编译器能力实验；不是知识引擎、实时 watcher 或视觉宿主的交付记录。

## 已确认方向

- `index.mbt.md` 组织目录、引用与依赖；正文仍是独立 Markdown 或其他格式。
- 核心使用 MoonBit，自有产品实现源码中 MoonBit 占比 >85%；统计细则建议见 PROPOSAL §12。
- 默认暴力向量搜索，可通过抽象对接外部模型和搜索实现；模型生成向量与向量搜索分别建接口。
- 采用真实资料和人工标注问题验证知识质量。
- 需要视觉页面时使用 `.mbt.md`；建议 `views/*.mbt.md` 定义页面，独立宿主绑定知识引擎数据，优先评估 MoonViz 渲染。

## 本机实际验证

工具链：`moon 0.1.20260920 (914d7da 2026-09-20)`，`moonc v0.10.14+7d59c7ec9 (2026-09-18)`。以 native 后端的独立 `.mbt.md` 文件执行，不修改同门项目。

| 实验 | 操作 | 实际结果 | 可得结论 |
| --- | --- | --- | --- |
| 有效声明 | 在 `mbt check` 块定义 `Array[String]` 路径列表和测试，执行 `moon check` | 退出码 0 | 受检声明可进行语法/类型检查 |
| 注入类型错误 | 把字符串路径改成整数 `42`，保留 `Array[String]` 返回类型 | 退出码 255，报告 `Int` 与 `String` 类型不匹配 | 编译器确实拒绝该类型错误 |
| 修复声明 | 恢复字符串路径后重新检查 | 退出码 0 | 修改后重新检查路径成立；尚未实现 watcher |
| 文学化测试 | 对有效文件执行 `moon test` | 1 项测试通过 | 受检块可作为声明形状测试的载体 |
| 文件缺失 | 字符串路径指向不存在的 `wiki/missing.md` | 上述 check/test 仍通过 | 普通路径字符串不会自动触发文件存在性验证 |

追加实验确认普通 `mbt` 定义块与后续 `mbt check` 块可以在本机独立文件中共享绑定并通过检查；MemoryCorridor 现把第一个 `mbt check` 块作为目录/视图 IR，允许后续块参与 MoonBit 编译。运行期解析器会扫描整份文件，同步拒绝未闭合的 `mbt` 与 `mbt check` 围栏，避免将编译输入误当成 Markdown 正文。该规则仍不等于完整 CommonMark/YAML 编译器，并建立了多块、未闭合块和编译失败正反例。

保留的最小样例：`docs/experiments/literate-index.mbt.md`。从仓库根可执行：

```sh
moon check docs/experiments/literate-index.mbt.md
moon test docs/experiments/literate-index.mbt.md
```

错误注入应在临时副本上进行，把 `["wiki/missing.md"]` 换成 `[42]` 后检查非零退出，再恢复检查。样例不导入尚不存在的引擎包，不代表生产声明 API 已定稿。

## 能力边界与落地方式

文学化编译提供索引代码的类型与语法检查。目录的唯一 id、文件存在性、内容哈希、引用完整性和来源依赖由引擎验证。实时行为由声明与外部内容的变更检测驱动，并在启动/重扫时用内容哈希兜底。

提交建议以候选索引校验和根声明最后发布为中心，配合写锁、基线检查、持久化恢复记录与幂等重试。编译通过不等于多文件提交完成；外部工具跨文件读取时的瞬时一致性仍需明确限制。

来源撤销可沿目录依赖使受影响页面失效，但索引编译不能判断一段自然语言是否已经彻底删除某来源的知识。第一版共享页标记待重编译，默认不参与检索，重生成后再恢复有效。

向量默认采用暴力余弦 top-k。`EmbeddingProvider` 供给文本向量，`VectorSearchBackend` 选择候选；外部模型单独接入时继续复用暴力搜索，完整外部搜索实现可替换默认后端。缺少向量时使用关键词检索，不把搜索算法等同于向量模型。

## 视觉页面实现方向

`index.mbt.md` 声明知识组织；`views/*.mbt.md` 声明视觉布局、组件、数据绑定与交互。页面以目录、搜索结果、正文和来源为数据输入，正文不复制进视觉声明。生成的 HTML/SVG/原生画面是派生输出。

本地 MoonViz 和 deepOffice 已有 `.mbt.md` 声明样例，可作为同门能力的调研入口；本轮没有复制其代码，也未验证全部动态绑定能力。建议优先适配 MoonViz，保持视觉宿主与知识核心独立，以“目录 → 搜索结果 → 详情/来源”的最小页面检验组件映射、数据刷新与交互动作。

## 尚未完成的验收

- 生产目录 DSL 的编译器与受限解析器一致性；依赖/内容变化后的自动刷新。
- 多文件写入故障注入、跨进程写锁、外部编辑冲突、来源撤销矩阵。
- 暴力向量实现、外部提供者覆盖、空间隔离与正文修改后的向量失效。
- 视觉 `.mbt.md` 的实际渲染、动态数据绑定及交互。
- 真实资料问答效果、成本、性能和源码占比门禁。
